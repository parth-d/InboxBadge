# InboxBadge

InboxBadge is a free, open-source macOS menu-bar app that shows how many unread emails each of your Gmail accounts has, lists the newest unread threads, and notifies you when new mail arrives. From the menu bar or a notification you can open a thread in your browser, mark it read, or move it to Trash.

- Several Gmail and Google Workspace accounts at once.
- Native macOS notifications with **Mark as read** and **Delete** buttons.
- Built for battery life: it checks for mail with one small request per account per minute and sleeps otherwise.
- Everything runs on your Mac. There is no InboxBadge server, no tracking and no analytics.

InboxBadge uses the Gmail API with your Google account's permission. You can read exactly what it accesses and how it handles data in the [privacy policy](privacy.md).

Source code and setup instructions: [github.com/parth-d/InboxBadge](https://github.com/parth-d/InboxBadge). Released under the MIT license.
